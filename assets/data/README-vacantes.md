# Vacantes Resumen

El mapa de calor lee primero `vacantes-resumen.csv`.

Formato esperado:

```csv
Local,,Pendientes
SABORES EXPRESS,,
SAAVEDRA,,3
HAMBURGUESAS EXTREMAS,,
APER MATADEROS,,15
```

Reglas:

- La primera columna debe tener el nombre del local.
- La tercera columna debe tener la cantidad de vacantes pendientes.
- Las filas `SABORES EXPRESS` y `HAMBURGUESAS EXTREMAS` separan cada marca.
- Los nombres de locales deben coincidir con las claves de coordenadas dentro de `pages/mapa-calor.html`.
